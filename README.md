# Proyecto JS Solo Productos

Proyecto Express + MySQL en capas, dejando únicamente el módulo de **productos**.

## Funcionalidades
- Listar productos
- Agregar productos
- Eliminar productos

## Rutas API
- `GET /api/productos`
- `POST /api/productos`
- `DELETE /api/productos/:id`

## Ejecutar
1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Configurar el archivo `.env` con tus datos de MySQL.
3. Iniciar el proyecto:
   ```bash
   node app.js
   ```
4. Abrir en el navegador:
   ```
   http://localhost:3000
   ```
